## Öğrenme Yolu

```
1. Temel Kavramlar (01-04)

2. Programlama (05-06)
   └── C# ile script yazma, input yönetimi

3. Görsel ve Ses (07-08)
   └── UI oluşturma, ses sistemi

4. Fizik ve Animasyon (09-11)
   └── Fizik motoru, animasyonlar, efektler

5. Sahne Yönetimi (12)
   └── Sahneler arası geçiş, veri taşıma
```
